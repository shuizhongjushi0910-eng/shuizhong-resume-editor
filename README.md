# 水中居士简历编辑器 · 网页版

浏览器内的简历编辑器：可编辑文字、调整板块顺序、修改版式与配色、上传及裁切照片，并直接下载 A4 PDF。

## 使用与保存

- 默认提供通用示例模板；请将示例文字换成自己的真实信息。
- 草稿保存在当前浏览器的本地存储（localStorage）中，不会作为简历内容上传到网站。清理浏览器数据可能删除草稿，请及时导出备份。
- 照片在浏览器内上传、预览及裁切；删除照片后仍可通过照片位置重新上传。
- 点击页面的 PDF 导出按钮即可下载简历。PDF 在浏览器内生成。
- 没有账号系统或云端同步：不同浏览器、设备、网址的草稿互不自动同步。
- 本仓库不包含作者的私人简历、电话、邮箱或证件照。

## GitHub Pages 发布

将本目录内的文件放到公开仓库中，在仓库 Settings → Pages 中选择对应分支的根目录发布。保留 index.html 与 web-info.js 的相对位置。无需安装依赖或购买后端服务器。

访问效果受 GitHub Pages 的服务可用性与访问网络影响。页面中的第三方链接由使用者自行填写。
